# 什么是机场节点？节点分类、入口落地结构与网络数据传输机制

在 Clash 的界面中，最核心的操作对象就是那一个个排列整齐的“节点”。无论是测速、切换路线还是配置规则分流，所有流量调度的最终落脚点都是具体的节点。那么，在网络工程的显微镜下，一个“节点”究竟包含哪些技术要素？它是如何将你的请求传递到世界各地的？本文为你系统拆解。

---

## 一、节点的本质定义：网络终结点的参数合集

在计算机网络协议中，一个“节点 (Proxy Node)”并不是一个空泛的概念，而是一个**经过严格加密与身份认证封装的远程代理终结点**。

在 Clash 的底层 YAML 配置文件中，一个节点实际上是一组标准参数定义：
- **服务器地址 (server)**：国内入口中转服务器的域名或 IP 地址。
- **端口 (port)**：中转服务器开放监听的端口号。
- **协议类型 (type)**：如 `ss` (Shadowsocks)、`trojan`、`vmess`、`vless` 等。
- **安全鉴权 (uuid / password)**：用于识别用户身份与计量流量的密码或密钥。
- **传输层配置 (tls / transport)**：例如 WebSocket、gRPC 或 Reality 伪装域名等。

只要这组参数被正确加载进客户端内核，本地便拥有了一个可以建立安全数据隧道的代理节点。详细配置结构可阅读[什么是Clash订阅？YAML配置结构解析](/posts/what-is-clash-subscription/)。

## 二、一个节点的完整物理生命周期

当你选定一个名为“日本 02 [中转]”的节点并打开 YouTube 观看视频时，数据流经历了以下四步跃迁：

```
[本地电脑 / 手机]
       ↓ (1. 本地加密，发送至本地混合端口 7890)
[Clash 内核透明分流]
       ↓ (2. 建立 TLS 隧道，发往国内入口 BGP 机房)
[国内中转入口服务器 (上海/广州)]
       ↓ (3. 经由内网专线或公网转发至海外)
[境外落地服务器 (东京 IDC 机房)]
       ↓ (4. 解密数据，向 YouTube 发起公网请求并回传)
[目标视频服务器 (Google CDN)]
```

1. **入口层**：负责以极高的速度接收来自各省市电信、联通、移动宽带用户的初次连接，起到网络接入与抗抖动的作用。
2. **骨干中转层**：负责将海量数据包跨越国境。采用 [IEPL专线节点](/posts/what-is-iepl-node/) 的链路在此阶段完全走封闭内网，免受公网国际出口拥堵影响。
3. **落地层**：处于目标地区的机房（如香港 Equinix、日本 SoftBank、美国 HE 等），负责将数据包向目标内容提供商交付。

## 三、机场节点的常见分类维度

### 1. 按物理链路架构划分
- **公网直连节点**：客户端直接连接海外落地机房，成本最低，但晚高峰丢包率高，目前仅作为廉价补充。
- **BGP 公网中转节点**：国内采用多线 BGP 机房接入，后端走优化公网路由出境，性价比均衡。
- **IEPL / IPLC 专线节点**：端到端内网光缆专线，不经过公网国际出口，抖动极低，适合对稳定性要求严苛的用户。

### 2. 按落地地区划分
- **亚太近距离节点 (香港 / 台湾 / 日本 / 韩国 / 新加坡)**：物理时延低（20ms - 80ms），适合日常办公、即时通讯与网页浏览。
- **欧美远距离节点 (美国 / 英国 / 德国等)**：物理时延较高（140ms - 220ms），但 IP 资源丰富、机房带宽充裕，适合大文件吞吐与冷门业务。详细场景对应可阅读[Clash节点选择与地区匹配实操指南](/posts/how-to-choose-clash-nodes/)。

### 3. 按业务特性与解锁能力划分
- **原生 IP / 流媒体解锁节点**：采用当地住宅带宽或专门广播的原生 IP，能完美绕过 Netflix、Disney+ 的 IDC 数据中心风控拦截。
- **AI 专用节点**：纯净无滥用记录的 IP，用于支持 OpenAI ChatGPT 与 Claude。

## 四、节点倍率的经济学常识

在节点列表中，经常看到带有 `(0.1x)` 或 `(3.0x)` 标记的节点：
- **倍率机制**：指你使用该节点所消耗的实际数据量乘以对应数值扣除账户额度。在 3x 节点下载 1GB 文件，后台会扣除 3GB 流量。
- 详细机制与避免流量迅速被扣完的技巧，请务必阅读专文：[什么是机场节点倍率？0.1x至10x扣费机制](/posts/what-is-node-multiplier/)。
