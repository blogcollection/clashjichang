# Android Clash手机端配置教程：Clash Meta for Android与常驻后台优化

在移动设备上使用代理工具，许多用户常遇到锁屏断连、国内应用打开变慢以及耗电异常等情况。本文详细讲解 Android 平台上基于最新开源内核的 **Clash Meta for Android (CMFA)** 客户端的完整配置流程，涵盖订阅导入、应用分流与系统后台保活策略。

---

## 一、环境要求与客户端准备

在开始配置前，请确保满足以下系统与网络环境：

1. **系统版本**：Android 7.0 及以上版本（推荐 Android 10+ 以获得完善的应用分流支持）。
2. **内核选型**：建议下载支持新协议的 **Clash Meta for Android**（简写为 CMFA，项目基于 Mihomo 开源内核构建），避免使用已停更的原版 CFA，后者无法识别部分新型节点。
3. **订阅来源**：准备好一条格式规范的 Clash 订阅链接。若尚未购买服务，可以先参考[新手入门价格较低机场推荐](/recommend/)或查阅[机场大全完整清单](/airports/)选择合规可靠的服务商。

---

## 二、订阅配置导入步骤

1. 打开 CMFA 应用，点击主界面的 **“配置” (Profiles)** 选项。
2. 点击右上角的 **“+”** 号，选择 **“URL / 从 URL 导入”**。
3. 在弹出的输入框中填写：
   - **名称**：自定义备注（例如 `我的主力机场`）。
   - **URL**：粘贴从服务商后台复制的 Clash 订阅链接。
   - **自动更新**：建议设置为 `1440` 分钟（即 24 小时自动刷新一次节点）。
4. 点击右上角的保存软盘图标，客户端会自动向远程服务器请求配置文件并解析。
5. 导入成功后，返回配置列表，点击选中刚才导入的配置卡片（右侧显示圆点高亮表示激活）。

若提示下载超时或解析错误，通常由于本地 DNS 污染阻断了订阅域名，可先查阅[Clash订阅下载失败排查指南](/posts/clash-subscription-download-failed/)。

## 三、核心设置：分流模式与应用分流配置

为了避免国内应用（微信、高德地图、网银、淘宝等）绕行海外节点导致加载缓慢或触发账号风控，必须正确配置分流规则：

### 1. 运行模式选择
返回主页，点击 **“代理” (Proxy)** 页面，右上角提供三种运行模式：
- **规则模式 (Rule - 推荐)**：依据配置文件中的域名和 IP 规则分流，国内网站走 DIRECT（直连），境外受限站点走 PROXY（代理）。
- **全局模式 (Global)**：所有出站流量均强制经过选中的单一节点，仅用于排查特定网站连接问题。
- **直连模式 (Direct)**：所有流量直出，不经过任何代理节点。

### 2. 应用分流（分应用代理）
1. 在 CMFA 主界面点击 **“设置” -> “网络” -> “分应用代理”**。
2. 开启分应用代理开关，选择 **“绕过所选应用” (Bypass selected apps)** 模式。
3. 在下方应用列表中，勾选不需要走代理的应用，例如微信、QQ、网易云音乐、支付宝和各大银行 App。这样即使节点发生波动，国内日常通信也丝毫不受影响。

## 四、系统后台保活与防掉线优化

安卓各家定制系统（MIUI/HyperOS、ColorOS、OriginOS、EMUI 等）普遍存在严格的后台管理，极易导致锁屏后 VPN 掉线：

1. **锁定多任务卡片**：打开系统最近任务列表，长按或下拉 Clash 应用卡片，点击“加锁”图标。
2. **电池无限制**：进入系统“设置” -> “应用管理” -> 找到 Clash -> “省电策略 / 电池管理”，将其修改为 **“无限制”** 或 **“允许完全后台行为”**。
3. **自启动权限**：在权限管理中，允许 Clash 开机自启及被关联唤醒。

---

## 五、验证生效与网络连接测试

完成上述设置后，点击主界面的 **“启动”** 按钮。系统会弹出“网络连接请求”授权对话框，点击“确定”。

1. **节点测速**：进入“代理”标签页，点击右下角的雷电/测速图标，观察节点延迟（通常在 30ms - 200ms 之间）。如果出现全部超时，请查看[Clash节点全部超时解决方案](/posts/clash-nodes-all-timeout-solutions/)。
2. **浏览器验证**：打开 Chrome 浏览器，访问海外搜索引擎与 IP 查询网站，核验出口 IP 归属地是否与所选节点地区一致。
3. **国内应用测试**：打开国内地图或外卖应用，确认能够准确定位并秒开图片，验证分流规则完全生效。

---

## 六、常见配置陷阱与维护要点

- **不要盲目使用高倍率节点**：部分机场提供 3x 或 5x 节点，虽然速度优秀但流量扣除极快。详细机制可参考[什么是机场节点倍率](/posts/what-is-node-multiplier/)。
- **定时清理缓存**：当机场节点变动后若连接异常，可在配置详情中手动刷新订阅，拉取最新服务器 IP。
