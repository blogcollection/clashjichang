# Clash Verge常用设置与TUN模式配置：接管非代理协议与局域网共享指南

在日常使用代理工具时，单纯的系统代理往往只能覆盖浏览器等标准 HTTP 协议应用。如果需要让游戏、终端、虚拟机以及同一局域网内的其它设备共享网络通道，就必须深入掌握 **TUN 模式** 与 **局域网共享 (Allow LAN)** 功能。

---

## 一、Clash Verge 核心设置项全解析

进入 Clash Verge 的“设置”页面，建议掌握以下关键参数的作用：

1. **混合端口 (Mixed Port)**：默认通常为 `7890`。它同时支持 HTTP 与 SOCKS5 代理协议，是绝大多数第三方软件手动配置代理时的核心入口。
2. **允许局域网连接 (Allow LAN)**：开启后，Clash 将监听 `0.0.0.0` 而非仅 `127.0.0.1`，允许同一局域网内的其他设备（手机、主机、电视盒子）通过本机网络转发流量。
3. **开机自启动与静默启动**：开启后，随系统启动并在后台托盘驻留，免去每次开机手动打开的麻烦。
4. **内核切换**：若当前客户端支持，建议选定 `Mihomo` 以获得最强协议兼容性。

---

## 二、TUN 虚拟网卡模式的完整配置步骤

TUN（Network TUNnel）是一种在操作系统网络层创建虚拟网卡的技术。开启后，无需对软件单独设置代理，所有流量均由驱动层捕获。

### 步骤 1：安装服务模式
1. 进入“设置” -> 找到 **“服务模式” (Service Mode)**。
2. 点击右侧的“安装”按钮，系统会弹出 UAC 提权确认，点击“是”。
3. 安装成功后，服务模式图标会变成绿色激活状态。

### 步骤 2：启用并微调 TUN 设置
1. 在设置中开启 **“TUN 模式”** 开关。
2. 此时 Windows 网络连接中会出现一个名为 `wintun` 的网卡设备（macOS 则为 `utun` 接口）。
3. 检查 TUN 配置参数：
   - **Stack (协议栈)**：通常选择 `gVisor` 或 `System`。推荐默认的 `gVisor`，性能损耗小且跨平台兼容性良好。
   - **DNS 劫持**：保持开启，确保所有的 DNS 查询请求均被送入 Clash 内部解析，彻底杜绝本地运营商的 DNS 污染。

## 三、局域网共享：为 Switch/PS5/手机提供代理

家中如果拥有 Nintendo Switch、PS5 游戏主机或 Apple TV 等无法直接安装客户端的设备，可以利用电脑上的 Clash Verge 提供局域网转发：

1. 在电脑端 Clash Verge 设置中打开 **“允许局域网” (Allow LAN)** 开关。
2. 在 Windows 系统的“命令提示符”中输入 `ipconfig`，找到本机局域网 IPv4 地址（例如 `192.168.31.50`）。
3. 拿起目标设备（以 Switch 为例）：
   - 进入系统设置 -> 互联网 -> 互联网设置 -> 连接当前 Wi-Fi。
   - 代理服务器设置改为 **“启用”**。
   - **服务器 (IP 地址)**：填写电脑的内网 IP `192.168.31.50`。
   - **端口**：填写 Clash 的混合端口 `7890`。
4. 保存并在 Switch 上进行网络连接测试。成功后，游戏商店下载及联机体验将显著提升。

## 四、DNS 调优：Fake-IP 与 Redir-Host 选型

Clash 内核处理 DNS 有两种主流机制：

1. **Fake-IP 模式 (推荐)**：内核在收到 DNS 请求时立即返回一个虚构的内网 IP（如 `198.18.0.x`），并记录映射关系；随后流量发往内核时再进行真正的远程解析。该机制消除了本地 DNS 往返延迟，极大提速网络建立，是现代客户端的标准配置。
2. **Redir-Host 模式**：本地必须先拿到真实的远端 IP 后再转发数据，在某些网络封锁严格或老旧环境下容易遭遇解析失败。
若对 DNS 原理感兴趣，可深入阅读[Clash DNS污染与DNS泄露排查指南](/posts/clash-dns-leak-and-pollution-guide/)。

## 五、维护与避坑建议

- **退出前关闭系统代理**：在关机或退出 Clash 前，尽量先关闭系统代理开关，防止残留错误的代理配置导致再次开机时浏览器无法上网。
