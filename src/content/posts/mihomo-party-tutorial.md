# Mihomo Party客户端新手与进阶指南：现代化界面、路由分流与多订阅管理

在代理客户端的发展历程中，用户对界面的美观度与多订阅管理的诉求日益增加。**Mihomo Party** 是一款基于开源 Mihomo 内核、采用现代 Web 技术与精美 UI 设计的新兴跨平台客户端。本文将全面介绍该客户端的安装、订阅聚合管理与路由调优。

---

## 一、软件特色与环境准备

1. **图形化体验**：相比老式客户端，Mihomo Party 拥有极具视觉冲击力的实时流量波形图、直观的节点地理位置标签与可视化的规则链视图。
2. **多订阅天然支持**：支持轻松添加多份机场订阅，并能在单一控制台内按节点地区、倍率自动分组与去重。
3. **系统兼容**：全面覆盖 Windows 10/11、macOS（Apple Silicon / Intel 原生支持）及主流 Linux 发行版。
4. **订阅准备**：准备一条可用的订阅链接。初次接触的用户可查看[新手低价机场选购指南](/posts/cheap-clash-airport-selection/)获取性价比套餐，或访问[机场推荐总览](/recommend/)。

---

## 二、安装与基础配置

1. 从官方 Releases 页面下载适合当前操作系统的安装文件（Windows 平台推荐 `.exe` 安装程序，macOS 下载 `.dmg` 文件）。
2. 安装后启动软件，首次进入会有友好的初始化向导：
   - 界面语言选择 **“简体中文”**。
   - 网络接口模式建议保持推荐设置。
3. 点击左侧 **“设置”**，可开启“开机自启”与“托盘最小化”。

---

## 三、导入并管理多份机场订阅

1. 点击左侧导航栏的 **“订阅”** 图标。
2. 点击右上角的 **“添加订阅”** 按钮。
3. 填入自定义机场名称与服务商提供的 Clash 订阅链接。
4. 点击 **“拉取配置”**，客户端会自动解析其中的节点与规则。
5. **多订阅管理优势**：
   - 如果你有主力专线机场与廉价备用大流量机场，可以同时导入两份订阅。
   - 在节点选择页面中，Mihomo Party 会将不同订阅以折叠标签形式清晰呈现，便于快速切换或混合分流。

---

## 四、代理分流与节点测速体验

1. 点击左侧 **“代理”** 选项卡。
2. 顶部提供工作模式切换：
   - **规则模式 (Rule)**：智能区分境内外流量。
   - **全局模式 (Global)**：全量转发至指定节点。
   - **直连模式 (Direct)**：不经代理。
3. **批量快速测速**：点击右上角的闪电图标，客户端会对列表内所有节点发起并发延迟测试，并以绿色（优质）、黄色（一般）、红色（超时）清晰着色。
4. 关于延迟数值的科学理解，建议阅读[Clash节点延迟怎么看：RTT与实际网速区别](/posts/how-to-read-clash-node-latency/)。

---

## 五、开启 TUN 模式与全局接管

对于需要代理终端 Git 操作或非浏览器应用的场景：

1. 进入“设置” -> “内核与网络”。
2. 开启 **“TUN 模式”**。系统会要求授权管理员权限，确认同意即可自动部署虚拟网卡驱动。
3. 开启后，本地所有的 TCP/UDP 流量都会受到 Mihomo 规则集的精准调度。
